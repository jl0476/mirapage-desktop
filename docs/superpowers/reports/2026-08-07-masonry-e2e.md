## 已知简化项（留后续打磨）

1. **像素级 scrollTop 锚定补偿**：E1 简化为 visibleRange 重算保证可见区正确；applyMeasuredBatch 已实现（C2）但未接入 MasonryView。实测 224 目录无明显跳动，大目录/慢速 I/O 场景若发现跳动再补。
2. **resolve in-flight cancel**：快速切目录时 useMasonrySettings.resolve 可能竞态（E3 review M-2），非阻塞。
3. **hasImages 搜索态副作用**：搜索时 sortedEntries 变化影响 hasImages（E3 review M-3），非阻塞。
4. **var(--ease-out) 残留**：FileList.details-header button / FileBrowser.tb-btn 预存在使用未定义变量（浏览器 fallback ease），非本模块引入，留后续清理。
